# Чек-лист устройства: захват уведомлений

> **Статус:** действует
>
> **Сверен:** 10 ноября 2026 — экран «Сбор пушей» и служба захвата из [`notification-capture.md`](../architecture/notification-capture.md); на устройствах ещё не проходился
>
> **Пересмотр:** при изменении службы захвата, доступа к уведомлениям или после прохода на новом устройстве

Ручная проверка захвата на реальном телефоне — то, что эмулятор не воспроизводит: оболочки
производителей, Doze, перезагрузка. Это проверка живучести слушателя этапа 0
([`mvp.md`](../product/mvp.md#проверить-до-кода)); её итог решает, нужны ли `requestRebind()` в
службе и онбординг автозапуска.

## Подготовка

- Сборка: `npm run build`, `npx cap sync android`, `./gradlew assembleDebug` в `android/`. APK —
  `android/app/build/outputs/apk/debug/app-debug.apk`.
- **Все сборки для одного телефона — с одной машины.** Debug-ключ у каждой машины свой, у CI тоже:
  APK с другой подписью поверх не встанет, а удаление стирает данные.
- Установка — только `adb install -r app-debug.apk` (USB или беспроводная отладка). APK файлом
  Play Защита блокирует: служба доступа к уведомлениям — в её списке чувствительных разрешений для
  приложений не из Play (проверено 11 ноября 2026). Через `adb` этой блокировки нет, и обычно нет
  «ограниченных настроек» Android 13+.
- Записать модель, версию Android и оболочки, версию Android System WebView (нужна 111+).

## Проверки

Каждую — со всеми переключателями производителя по умолчанию; если не прошла — повторить с ними (см.
ниже) и записать, какой помог. После каждого шага — оплатить что-нибудь картой (или дождаться пуша) и
посмотреть, попал ли он в «Пойманные уведомления». Нет его там, но есть строка банка на это время в
«Отброшено: нет суммы» — служба жива, а формат не распознал фильтр суммы (ADR-0004): переслать текст
пуша из шторки. Нет и там — пуш не дошёл до службы.

| # | Действие | Ожидание |
| --- | --- | --- |
| 1 | «Разрешить доступ» на экране «Сбор пушей» | Открывается переключатель приложения; после включения и «назад» — «Доступ включён», «Служба на связи», событие «Служба подключилась» |
| 2 | Выбрать приложения банков и SMS (у SMS-приложения по умолчанию — пометка) | Список с иконками на экране «Сбор пушей»; уведомления других приложений и SMS без суммы в журнал не попадают |
| 3 | Пуш при открытом приложении | Появляется в журнале сам, без перезахода |
| 4 | Пуш при свёрнутом приложении | В журнале при возврате |
| 5 | Свайп приложения из недавних, затем пуш | В журнале; если нет — служба умирает вместе с задачей |
| 6 | Перезагрузка телефона, приложение не открывать, пуш | В журнале; событие «Служба подключилась» с «через N с после включения телефона» |
| 7 | Ночь без зарядки (Doze), утром пуш | В журнале; нет ли «Служба отключилась» без последующего подключения |
| 8 | Обновление поверх: собрать заново, `adb install -r` | Доступ остаётся; служба снова подключается сама — или видно, что нужна «Перезапустить службу» |
| 9 | Пуш, пока служба отвязана (после шагов 5–8, если она не на связи), затем «Перезапустить службу» | Пуш, ещё висящий в шторке, — в журнале с пометкой «пропущено, найдено в шторке» |

## Переключатели производителей

- **Realme UI (Realme 11 Pro+ 5G, RMX3741, Android 15).** Через `adb` ставится без Play Защиты и
  без «ограниченных настроек» (`ACCESS_RESTRICTED_SETTINGS` — allow), проверено 11 ноября 2026.
  Если служба умирает: «Автозапуск», «Батарея» → «Разрешить фоновую активность», замок карточки в
  недавних.
- **Flyme (Meizu, Android 9).** Ограниченных настроек нет. Если служба умирает: приложение
  «Безопасность» → разрешения → автозапуск и фоновая работа приложения; блокировка в недавних.
  Проверить версию WebView: ниже 111 приложение покажет страницу «обновите WebView».

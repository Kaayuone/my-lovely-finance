# ADR-0004. Захват сохраняет только уведомления, где названа сумма в валюте

- **Статус:** принято
- **Дата:** 11 ноября 2026
- **Этап:** этап 1, версия «для себя»
- **Связанные документы:** [`notification-capture.md`](../architecture/notification-capture.md),
  [ADR-0003](0003-captured-notifications-go-to-a-native-queue-the-app-takes-them-from.md),
  [`product/bank-notifications.md`](../product/bank-notifications.md)

## Контекст

Белый список работает на уровне приложения. Для приложения банка этого хватает, но SMS-приложение
или мессенджер несут и банковские сообщения, и личную переписку, коды, рассылки. С белым списком из
одних пакетов захват сохранял всю переписку выбранного SMS-приложения — владелец увидел это в первый
же день проверки. Android при этом даёт слушателю все уведомления телефона: сузить поток на стороне
системы до нужных приложений нельзя, только отбросить лишнее у себя.

## Рассмотренные варианты

**Фильтр по сумме.** Служба сохраняет уведомление, только если в его текстах есть число рядом с
валютой — кодом ISO, символом или словом («руб», «тенге»). Без настройки, одинаково для банков и SMS;
переписка без сумм не сохраняется. Цена — часть разбора на Java рядом с разборщиком на TS, и формат
без валюты потерялся бы молча. Принято.

**Белый список отправителей для SMS.** Точнее: сохраняется только переписка с выбранными
отправителями. Но выбрать отправителя можно только из тех, кого приложение уже видело, — то есть
хранить имена всех собеседников; и это ещё одна настройка, которую человек должен понять. Отвергнуто
для этапа 1; может вернуться как дополнение к фильтру по сумме.

**Режим на приложение: «всё» или «только с суммой».** Сохраняет все пуши банков для изучения
форматов, но добавляет переключатель, смысл которого надо объяснять, а у банковских пушей без суммы
(вход в приложение, реклама) ценности для учёта нет. Отвергнуто.

## Решение

- `CaptureAmounts.containsAmount` проверяет заголовок, текст, развёрнутый текст, подтекст и строки
  уведомления; без суммы уведомление не сохраняется — ни новое, ни найденное в шторке.
- Проверка нарочно шире разборщика: лишнее совпадение стоит одной записи, которую разборщик отбросит,
  а пропуск теряет операцию навсегда. Число — с разделителями тысяч и дробной частью, валюта — с
  любой стороны от него; буквенный код валюты не должен быть частью слова (`USDT`, «рубрика»).
- Версия 2 схемы `capture.db` удаляет уже сохранённые уведомления без суммы.
- Отброшенное уведомление выбранного приложения оставляет след без текста — приложение и время
  (`skipped_notifications`, версия 3 схемы). Экран «Сбор пушей» показывает их разделом «Отброшено:
  нет суммы»: так операция, которую отсёк фильтр, отличается от пропущенной службой.
- Правило покрыто JUnit-тестом `CaptureAmountsTest`, в том числе на форматах банков владельца.

## Последствия

- Формат операции без валюты в тексте захват не сохранит. Признак — в «Отброшено: нет суммы» есть
  запись банка на время покупки; текст человек берёт из шторки или приложения банка, и список валют
  и слов расширяется, а не фильтр выключается.
- Список валют живёт в Java; разборщик на TS ведёт свой. Новая валюта добавляется в оба.
- Если фильтр отменят, личная переписка выбранных SMS-приложений снова будет сохраняться, и раскрытие
  на экране «Сбор пушей» придётся переписать.
